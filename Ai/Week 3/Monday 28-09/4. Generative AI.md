## 1. What is Generative AI?

**Generative AI** is a class of AI models that can **create new content from user input**.

It can work with different types of **inputs** and produce different types of **outputs**, including:

- Text
    
- Images
    
- Audio
    
- Video
    
- Code
    

Models can also combine multiple input and output types.

### Examples

- **Image → Image + Text:** Analyse an image and generate a new image along with a description.
    
- **Image + Text → Video:** Use an image and a written prompt to generate a video.
    

---

## 2. Generative AI Input → Output Types

Generative models are often described using the format:

**Input type → Output type**

Common examples include:

- **Text → Text**
    
- **Text → Image**
    
- **Text → Video**
    
- **Text → Code**
    
- **Text → Speech**
    
- **Image + Text → Image**
    

This terminology describes **what the model receives** and **what it produces**.

---

## 3. How Does Generative AI Work?

At a high level, generative AI models:

1. **Learn patterns from large amounts of data.**
    
2. **Identify relationships and structures within that data.**
    
3. **Use what they have learned to generate new content.**
    

The goal is not simply to copy the training data, but to **produce new outputs that follow patterns learned from the data**.

### Simple analogy

Generative AI can be compared to people who learn by observing examples:

- **Comedians** study other comedians to learn styles, timing and patterns of speech.
    
- **Artists** study many paintings to learn techniques and artistic styles.
    
- **Cover bands** listen to music to learn how to reproduce particular musical styles.
    

Similarly, generative models learn patterns from examples and use those patterns to create new content.

---

## 4. How Are Generative Models Trained?

### Initial training

Generative models are often initially trained using **unsupervised or self-supervised learning**.

During this stage, the model learns patterns and relationships within its training data.

For example, a language model may learn:

- Which words commonly occur together
    
- How sentences are structured
    
- Patterns in different writing styles
    
- Relationships between concepts
    

### Further training

After initial training, a model may be trained further using techniques such as:

- **Supervised learning**
    
- **Reinforcement learning**
    

This additional training can help the model perform specific tasks more effectively.

### Examples of specialised tasks

A model might be trained to:

- Summarise an article
    
- Answer questions
    
- Edit an image
    
- Follow instructions
    
- Generate or modify code
    

---

## 5. Key Idea

> **Generative AI learns patterns from data and uses those patterns to generate new content based on user input.**

A useful way to remember the process is:

**Training data → Learn patterns → Generate new content**

And generative models can be categorised by:

**Input → Output**
