
## What Is a Model?

- In **supervised learning**, a model is a complex collection of numbers that defines the **mathematical relationship between input features and output labels**.
    
- The model discovers these patterns through **training**.
    
- Before a supervised model can make predictions, it must be trained using a **dataset containing labelled examples**.
    

## How Does a Model Learn?

- The model's goal is to find the **best solution for predicting labels from features**.
    
- It does this by comparing its **predicted value** with the **actual label value**.
    
- The difference between the predicted value and the actual value is measured using **loss**.
    
- The model uses the loss to gradually **update its solution**, improving its predictions over time.
    
- In other words, the model learns the mathematical relationship between the **features** and the **label** so that it can make accurate predictions on **unseen data**.
    
- [See loss: https://developers.google.com/machine-learning/crash-course/linear-regression/loss](https://developers.google.com/machine-learning/crash-course/linear-regression/loss)
    

### Example: Predicting Rainfall

- Suppose a model predicts **1.15 inches of rain**.
    
- The actual rainfall is **0.75 inches**.
    
- The model calculates the loss based on the difference between its prediction and the actual value.
    
- The model then modifies its solution so that its future predictions are closer to **0.75 inches**.
    
- After the model has processed each example in the dataset, sometimes multiple times, it arrives at a solution that makes the best predictions **on average** across the training examples.

## How the Model Improves

- The model gradually learns the **relationship between the features and the label**.
    
- This gradual learning is one reason why **large and diverse datasets** can help produce better models.
    
- By seeing more data with a wider range of values, the model has more opportunities to **refine its understanding** of the relationship between the features and the label.
    

## Adjusting Features During Training

- During training, **ML practitioners** can make adjustments to the configurations and features that the model uses to make predictions.
    
- Some features may have **more predictive power** than others.
    
- Therefore, ML practitioners can select which features the model uses during training.
    

### Example: `time_of_day`

- Suppose a weather dataset contains a feature called **`time_of_day`**.
    
- An ML practitioner could train the model:
    
    - With `time_of_day`
        
    - Without `time_of_day`
        
- They can then compare the model's predictions to determine whether including `time_of_day` helps the model make better predictions.
    

### Key Idea

**Training is an iterative process:**

**Features → Prediction → Compare with actual label → Calculate loss → Update model → Repeat**

Through this process, the model gradually learns a mathematical relationship that can be used to make predictions on **unseen data**.
