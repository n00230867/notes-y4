- The k-nearest neighbours algorithm is a supervised learning model that uses proximity to make predictions about the classification of a data point.

- k refers to the number of neighbours that are considered in making a prediction.

**Advantages:** The k-Nearest Neighbors algorithm is simple to implement and robust to **noisy training data**.

**Disadvantages:** High cost of computation compared to other algorithms.

- Storage of data: memory based, so less efficient.

- Need to define which k value to use.

| - **Noisy training data:** data containing errors, **outliers,** or other irrelevant information that can negatively impact a machine learning model's performance and lead to poor predictions |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| - **Outliers** are data points that significantly differ from other observations in a dataset, often resulting from errors in measurement, data entry, or genuinely rare events                 |
