## 1. What is Data?

Data can take many forms, including:

- **Words and numbers** stored in tables
    
- **Pixel values** captured in images
    
- **Waveform values** captured in audio files
    

Related data is organised into **datasets**.

### Examples of datasets

A dataset could contain:

- Images of cats
    
- Housing prices
    
- Weather information
    

---

## 2. Examples, Features and Labels

A dataset is made up of individual **examples**.

You can think of an **example** as being similar to a **single row in a spreadsheet**.

Each example can contain:

- **Features** — the information the model uses to make a prediction.
    
- **Label** — the "answer" or value that the model is trying to predict.
    

### Example: Weather Prediction

Suppose we want to build a model that predicts **rainfall**.

The **features** could include:

- Latitude
    
- Longitude
    
- Temperature
    
- Humidity
    
- Cloud coverage
    
- Wind direction
    
- Atmospheric pressure
    

The **label** would be:

- Rainfall amount
    

**Features → Model → Label prediction**

# 3. Dataset Size and Diversity

A dataset can be characterised by two important properties:

### Size

**Size** refers to the **number of examples** in a dataset.

For example:

- 1,000 examples = relatively small
    
- 1,000,000 examples = much larger
    

### Diversity

**Diversity** refers to the **range of situations represented by the examples**.

A dataset should ideally be both:

- **Large** — contains many examples
    
- **Diverse** — covers a wide range of conditions
    

### Important distinction

A dataset can be:

- Large and diverse
    
- Large but not diverse
    
- Small but highly diverse
    
- Small and not diverse
    

Therefore:

> **A large dataset does not necessarily have sufficient diversity.**

And:

> **A highly diverse dataset does not necessarily contain enough examples.**

---

## 4. Why Size and Diversity Matter

Consider a dataset containing **100 years of weather data**, but only for the month of **July**.

Although the dataset is large, it does not represent different seasons.

Using this dataset to predict **January rainfall** could result in poor predictions because January conditions are not represented.

Conversely, imagine a dataset containing weather data for **every month**, but only covering a few years.

This dataset is more diverse, but it may not contain enough years to account for **long-term weather variability**.

### Key idea

A useful dataset needs a good balance of:

**Enough examples + sufficient diversity**

---

# 5. Number of Features

Datasets can also be characterised by the **number of features** they contain.

Some datasets may contain **hundreds of features**, while others may contain only a few.

### Example: Weather Dataset

A complex weather dataset might contain features such as:

- Satellite imagery
    
- Cloud coverage
    
- Temperature
    
- Humidity
    
- Atmospheric pressure
    
- Wind speed
    
- Wind direction
    
- And many others
    

A simpler weather dataset might contain only:

- Temperature
    
- Humidity
    
- Atmospheric pressure
    

---

## 6. More Features ≠ Always Better

Having more features can help a model discover **additional patterns** in the data and potentially make better predictions.

However:

> **More features do not always result in better predictions.**

Some features may have little or no **causal relationship** to the label.

Including irrelevant features can add unnecessary information and may make it harder for a model to learn useful patterns.

### Key takeaway

The goal is not simply to have **as many features as possible**.

The goal is to have **useful features that provide relevant information about the label**.
